Writing your own indicator

Stockyard indicators are small TypeScript or JavaScript files. Open Indicators → + Your own to write or paste one, or Import file (or drag a .ts/.js file onto the shop) to add one someone shared. The editor test-runs the code as you type and shows what's wrong in plain words.

export default indicator({
  name: "EMA Trend Bands",
  shortName: "EMA Bands",          // shown in the chart legend
  description: "An EMA with bands one ATR above and below it.",
  placement: "overlay",            // "overlay" = on the price chart, "pane" = own panel below
  inputs: {
    length: input.length(21, "EMA length"),
    mult: input.float(1, "ATR multiplier", { min: 0.1, max: 10 }),
    source: input.source("close"),
  },
  plots: {
    basis: { label: "EMA", color: "#8b7bff" },
    upper: { label: "Upper", lineWidth: 1 },
    lower: { label: "Lower", lineWidth: 1 },
  },
  compute(bars, inputs) {
    const price = ta.source(bars, inputs.source);
    const basis = ta.ema(price, inputs.length);
    const atr = ta.atr(bars, 14);
    return {
      basis,
      upper: ta.zip((b, a) => b + inputs.mult * a, basis, atr),
      lower: ta.zip((b, a) => b - inputs.mult * a, basis, atr),
    };
  },
});

What the code gets

  • bars: the chart's candles, oldest first: { time, open, high, low, close, volume }.
  • inputs: the current settings, keyed like inputs above. Numbers are numbers, input.bool is true/false.
  • ta: the same building blocks the built-in indicators use (see src/indicators/ta.ts): sma ema rma wma hma dema tema vwma alma kama mcginley linreg ma, rsi stoch dmi atr tr obv accdist vwap, sum highest lowest highestBars lowestBars stdev dev correlation logReturns change mom roc cum shift, zip map crossover crossunder source. Each takes and returns one value per bar, with undefined while warming up.
  • input: length (a bar count), int, float, source, select(default, options), bool.

compute returns one array per plot (or a single array when there's one plot). NaN, null and missing values become gaps.

Plot options

label, color (hex or rgb/rgba), lineWidth 1–4, style: line, step, dots or histogram. Histograms take colorMode: sign (above/below zero), change (rising/falling), candle (candle direction) or macd (four shades).

Indicator-level options: levels: [70, 30] (dashed guide lines in a pane), range: [0, 100] (fixed pane scale), format: "price" | "volume" | "number", warmup (bars of history needed), author, version, category.

Safety

Custom indicators run in a separate sandbox thread. They see only the chart's candles: no access to the app, your settings, your API keys, files or the internet. One that runs longer than 4 seconds is stopped and marked as stuck until its code changes.

Agent bridge contract (Rust shell <-> web view)

Goal: AI agents (Claude Desktop, Claude Code, scripts) control Stockyard through one command registry that lives in the web view. Rust is a dumb, authenticated pipe.

Discovery file

<data_dir>/app.opencharts.desktop/agent.json, where <data_dir> is

  • macOS: $HOME/Library/Application Support
  • Windows: %APPDATA%
  • Linux: $XDG_DATA_HOME or $HOME/.local/share

Contents: { "port": 47821, "token": "<64 hex chars>", "pid": 1234 }. Mode 0600 on Unix. The token is created once and reused across launches (so HTTP clients keep working); agent_regenerate_token replaces it. The file is removed (or port set to null) when the server stops.

HTTP server (Rust, src-tauri/src/agent.rs)

Listens on 127.0.0.1 only, port 47821, falling back to any free port. Runs only while enabled. Every request must have:

  • Host of 127.0.0.1:<port> or localhost:<port>
  • no Origin header (blocks web pages in a browser)
  • Authorization: Bearer <token> Otherwise 403 (401 for a bad token). Body limit 2 MB. Anything that passes is forwarded.

Forwarding: Rust emits the Tauri event agent://request with payload

{ id: number; method: string; path: string; headers: Record<string, string>; body: string }

headers holds lowercased names, only: content-type, mcp-session-id, x-stockyard-client, accept. The web view answers with invoke("agent_reply", { id, status, headers, body }) (headers: Record<string,string>, body: string). Rust waits up to 180 s (approval prompts), then replies 504.

Routes (handled in the web view, src/agent/http.ts)

  • POST /mcp MCP Streamable HTTP, JSON responses only (no SSE). Notifications -> 202, empty body. initialize returns an Mcp-Session-Id header. GET /mcp and DELETE /mcp -> 405.
  • GET /v1/commands -> { commands: [{ name, title, description, access, inputSchema }] }
  • POST /v1/commands/<name> with a JSON object body -> { ok: true, result } or { ok: false, error } (status 200 / 400 bad input / 403 not allowed / 404 unknown / 500).

Tauri commands (Rust)

  • agent_set_enabled(enabled: bool) -> AgentStatus
  • agent_status() -> AgentStatus
  • agent_reply(id: u64, status: u16, headers: HashMap<String,String>, body: String)
  • agent_regenerate_token() -> AgentStatus
  • agent_install_claude_desktop() -> { configPath: string }: merges mcpServers.stockyard = { command: <current exe>, args: ["mcp"] } into Claude Desktop's claude_desktop_config.json (macOS ~/Library/Application Support/Claude/, Windows %APPDATA%\Claude\), keeping every other key, after writing a .bak copy.
interface AgentStatus { running: boolean; port: number | null; url: string | null; exePath: string; discoveryPath: string; token: string | null; error?: string }

Same binary, two extra modes (src-tauri/src/main.rs)

  • Stockyard mcp: stdio MCP bridge. Reads newline-delimited JSON-RPC from stdin, POSTs each to /mcp (token + port from agent.json, re-read on each failure), writes each JSON response on one line to stdout. Remembers clientInfo.name from initialize and the Mcp-Session-Id, sends them as x-stockyard-client / mcp-session-id. If Stockyard is not reachable, a request with an id gets a JSON-RPC error: "Stockyard isn't open, or Allow agents is off (Settings > Agents)." Never starts the GUI.
  • Stockyard cli <command> [json-args] and Stockyard cli list: one POST to /v1/commands/<command>, prints the JSON result, exit code 0/1. On Windows it attaches to the parent console first so output shows.

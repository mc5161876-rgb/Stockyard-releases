Stockyard plugins

A plugin adds widgets and themes to Stockyard. It is one JavaScript module file. People install it from Settings → Widgets & plugins → Add plugin file. community/items/plugin/big-movers.plugin.js is a complete example.

// @name My plugin
export default function activate(stockyard) {
  stockyard.registerWidget({
    id: "me.hello",
    name: "Hello",
    description: "Says hello",
    icon: "👋",
    defaultSize: { w: 220, h: 120 },
    defaultConfig: { who: "world" },
    settings: [{ key: "who", label: "Who", type: "text" }],
    mount(el, ctx) {
      el.textContent = `Hello, ${ctx.config.who}`;
      return { update: (ctx) => (el.textContent = `Hello, ${ctx.config.who}`) };
    },
  });
}

The // @name line sets the name shown in Settings. Installing a file with the same name replaces the old version. activate may return a cleanup function.

API (apiVersion: 1)

Member What it does
registerWidget(def) Adds a widget type to the Widgets menu. Returns a function that removes it.
registerTheme(theme) Adds a theme. Fields match the theme editor: bg, panel, panelAlt, border, hover, grid, text, muted, up, down, crosshair, accent, palette, light, and animation: { kind, intensity, speed, colors } with kind one of aurora, synthwave, rain, starfield, embers, waves, pulse. Invalid colors fall back to the default theme.
getTheme() The active theme's colors. Widgets can also use the CSS variables --bg, --panel, --panel-alt, --border, --hover, --text, --muted, --up, --down, --accent.
openSymbol(symbol) Shows a symbol on the main chart: BTC-USD, or tradier:AAPL for stocks.
markets.getBars(symbol, timeframe, { from, to }) Historical candles (times in Unix seconds).
markets.subscribeQuotes(symbols, onQuote) Live { symbol, last, reference, high24h, low24h, volume24h }. Returns an unsubscribe function.
markets.search(text) Symbol search.
getJson(url) GET a JSON URL. In the desktop app only hosts Stockyard allows can be reached.
React React, for plugins that want React.createElement and hooks in a component.
appVersion The Stockyard version.

Widget definition

Field Meaning
id Unique. Prefix it with your name, like acme.weather.
name, description, icon Shown in the Widgets menu. icon is an emoji or a short text.
defaultSize, minSize In pixels.
defaultConfig The widget's own settings, saved per placed widget.
settings Fields Stockyard draws in the widget's settings panel: text, textarea, number, toggle, select.
settingsNote A note at the top of that panel.
mount(el, ctx) Draw into el. Return { update(ctx), destroy() } (both optional). update runs when the config, size or theme changes.
component A React component that gets ctx as props, instead of mount.

ctx has config, setConfig(patch), width, height, theme, openSymbol(symbol), setTitle(text) and openSettings().

What a plugin can reach

A plugin runs inside Stockyard with the same access as the app's own code. It can read prices and settings. It cannot read the Alpaca, Tradier or X keys, which stay in the system keychain and are used only by the desktop backend. Network access is limited to the hosts Stockyard allows. A widget that crashes shows an error in its own box and doesn't affect the rest of the app. Turning a plugin off removes its widgets and themes right away.
